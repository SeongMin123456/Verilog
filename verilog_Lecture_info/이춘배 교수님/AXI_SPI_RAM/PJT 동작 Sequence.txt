CMD, Addr, WR_Data, RD_Data 신호 사용 예시
AXI Slave와 SPI Master 사이의 CMD, Addr, WR_Data, RD_Data 신호들은 주로 PS(Processing System)가 SPI Master의 동작을 제어하고 상태를 확인하기 위해 사용됩니다. 몇 가지 구체적인 예시를 통해 이 신호들이 어떻게 활용되는지 살펴보겠습니다.

가정:

SPI Master 내부에 다음과 같은 레지스터가 있다고 가정합니다.

0x00: 상태 레지스터 (읽기 가능, 통신 상태, 에러 플래그 등)

0x04: 제어 레지스터 (쓰기 가능, 통신 시작 명령, 클럭 분주 설정 등)

0x08: 전송 데이터 길이 레지스터 (쓰기 가능, 전송할 데이터 바이트 수 설정)

0x0C: 수신 데이터 버퍼 (읽기 가능, 수신된 데이터 저장)

예시 1: SPI 통신 속도 설정

PS가 SPI 통신 속도를 변경하기 위해 SPI Master의 클럭 분주 값을 설정하는 상황입니다.

PS: "SPI 통신 속도를 1MHz로 설정해야겠어." 라고 결정합니다.

PS -> AXI Slave:

Addr: SPI Master 내부의 제어 레지스터 주소인 0x04를 지정합니다.

WR_Data: 1MHz에 해당하는 클럭 분주 값 (예: 0x0A)을 지정합니다.

CMD: "쓰기" 명령을 나타내는 특정 값 (예: 0x01)을 지정합니다.

AXI Slave -> SPI Master: AXI 버스를 통해 해당 정보가 전달됩니다.

SPI Master: CMD를 확인하여 쓰기 동작임을 인지하고, Addr에 지정된 제어 레지스터(0x04)에 WR_Data 값 (0x0A)을 씁니다. 이제 SPI Master는 설정된 클럭 분주 값으로 동작합니다.

예시 2: SPI 데이터 전송 시작 (쓰기)

PS가 특정 데이터를 SPI Slave로 전송하도록 SPI Master에게 명령하는 상황입니다.

PS: "RAM에서 데이터를 읽어서 SPI Slave로 보내야지." 라고 결정합니다. (이전 단계에서 RAM 데이터 준비가 완료되었다고 가정합니다.)

PS -> AXI Slave:

Addr: SPI Master 내부의 제어 레지스터 주소인 0x04를 지정합니다.

WR_Data: SPI 데이터 전송 시작을 나타내는 특정 값 (예: 0x02)을 지정합니다. 이 값은 SPI Master가 미리 정의된 방식으로 데이터를 가져오거나, 추가적인 설정 (예: 전송할 데이터의 RAM 주소)을 참조하도록 할 수 있습니다.

CMD: "쓰기" 명령을 나타내는 특정 값 (예: 0x01)을 지정합니다.

AXI Slave -> SPI Master: AXI 버스를 통해 해당 정보가 전달됩니다.

SPI Master: CMD를 확인하여 전송 시작 동작임을 인지하고, 제어 레지스터(0x04)에 쓰기 명령을 실행합니다. 이후 SPI Master는 설정된 방식에 따라 RAM에서 데이터를 읽어 SPI Slave로 전송하는 과정을 시작합니다. (이 과정은 블록 다이어그램에는 명시되지 않았지만, 내부적으로 DMA 또는 FIFO를 사용할 수 있습니다.)

예시 3: SPI 데이터 수신 완료 확인

PS가 SPI Slave로부터 데이터 수신이 완료되었는지 확인하는 상황입니다.

PS: "SPI Slave로부터 데이터가 다 도착했는지 확인해야겠어." 라고 결정합니다.

PS -> AXI Slave:

Addr: SPI Master 내부의 상태 레지스터 주소인 0x00을 지정합니다.

CMD: "읽기" 명령을 나타내는 특정 값 (예: 0x00)을 지정합니다. WR_Data는 이 경우 사용되지 않거나 의미 없는 값이 될 수 있습니다.

AXI Slave -> SPI Master: AXI 버스를 통해 해당 정보가 전달됩니다.

SPI Master: CMD를 확인하여 읽기 동작임을 인지하고, Addr에 지정된 상태 레지스터(0x00)의 값을 읽어서 AXI Slave로 전달합니다.

AXI Slave -> PS:

RD_Data: SPI Master로부터 읽어온 상태 레지스터 값 (예: 0x01 - 수신 완료)을 PS에게 전달합니다.

PS: RD_Data 값을 확인하여 데이터 수신이 완료되었음을 인지합니다.

예시 4: 수신된 데이터 읽기

PS가 SPI Slave로부터 수신된 데이터를 읽어오는 상황입니다.

PS: "SPI Slave로부터 받은 데이터를 확인해야지." 라고 결정합니다. (이전 단계를 통해 수신 완료를 확인했다고 가정합니다.)

PS -> AXI Slave:

Addr: SPI Master 내부의 수신 데이터 버퍼 주소인 0x0C를 지정합니다.

CMD: "읽기" 명령을 나타내는 특정 값 (예: 0x00)을 지정합니다.

AXI Slave -> SPI Master: AXI 버스를 통해 해당 정보가 전달됩니다.

SPI Master: CMD를 확인하여 읽기 동작임을 인지하고, Addr에 지정된 수신 데이터 버퍼(0x0C)의 값을 읽어서 AXI Slave로 전달합니다.

AXI Slave -> PS:

RD_Data: SPI Master로부터 읽어온 수신 데이터 값 (예: 0xAB)을 PS에게 전달합니다.

PS: RD_Data 값을 확인하여 수신된 데이터를 획득합니다.

이처럼 CMD, Addr, WR_Data, RD_Data 신호들은 PS가 SPI Master의 레지스터를 읽고 쓰면서 SPI 통신을 제어하고 필요한 정보를 얻는 데 핵심적인 역할을 합니다. CMD 신호는 수행할 동작의 종류를 지시하고, Addr 신호는 접근할 레지스터의 위치를 지정하며, WR_Data는 쓸 데이터를 제공하고, RD_Data는 읽어온 데이터를 전달합니다. 시스템 설계에 따라 CMD 값의 의미나 레지스터 주소는 달라질 수 있습니다.
